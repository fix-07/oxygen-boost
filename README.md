# Oxygen Boost — متجر إلكتروني (React + Vite)

متجر عربي بالكامل (RTL) لبيع موسّع الأنف المغناطيسي واللصقات البديلة داخل ليبيا،
بهوية سوداء/زرقاء مستخرجة من شعار العلامة، ومصمّم أساساً للجوال.

---

## التشغيل

```bash
cd oxygen-boost && npm install && npm run dev
```

ثم افتح <http://localhost:5173>

للبناء للنشر:

```bash
npm run build
```

يخرج الموقع الجاهز في مجلد `dist/`.

---

## ⚠️ قبل النشر — خطوات إلزامية

كل هذه القيم في ملف واحد: [`src/config.js`](src/config.js)

| القيمة | الوضع الحالي | المطلوب |
| --- | --- | --- |
| `whatsapp` | `218910000000` **(رقم وهمي)** | رقم واتساب الحقيقي، صيغة دولية بدون `+` وبدون صفر بادئ |
| `whatsappDisplay` | `+218 91 000 0000` | الرقم كما يُعرض للزائر |
| `email` | `info@oxygenboost.ly` | البريد الحقيقي |
| `instagram` | `oxygenboost.ezone.ly` | ✅ صحيح |
| `deliveryFee` / `freeDeliveryOver` | `10` / `250` | أسعار التوصيل الفعلية |
| `analytics.ga4` | فارغ | معرّف Google Analytics 4 |
| `analytics.metaPixel` | فارغ | معرّف Meta Pixel |
| `howToVideo` | فارغ | رابط فيديو الشرح (YouTube embed أو ملف `.mp4`) |

بقيّة الأمور المطلوبة قبل الإطلاق:

1. **الأسعار** — القيم الحالية تقديرية في [`src/data/products.js`](src/data/products.js). عدّلها هناك أو من لوحة التحكم.
2. **صورة المشاركة** — `public/og.svg` رسم مؤقّت. واتساب وفيسبوك **لا يعرضان صور SVG** في معاينة الروابط،
   لذا صدّر صورة `1200×630` بصيغة JPG باسم `public/og.jpg` وغيّر وسم `og:image` في `index.html`.
   هذا مهم لأن أغلب زياراتك ستأتي من إنستقرام وواتساب.
3. **الشعار** — `public/logo.svg` و`public/mark.svg` إعادة رسم تقريبية للشعار المرفق.
   استبدلهما بملف الشعار الأصلي (SVG أو PNG شفاف) للحصول على مطابقة تامة.
4. **آراء العملاء** — النصوص الحالية *مبدئية ومكتوب عليها ذلك بوضوح* في
   [`src/data/content.js`](src/data/content.js). استبدلها بآراء حقيقية فقط.
5. **الدومين** — غيّر `SITE.url` وحدّث `public/robots.txt`.

## استبدال الرسوم بصور حقيقية

كل صور المنتجات حالياً رسوم SVG مدمجة (سريعة، بلا طلبات شبكة، ومتوافقة مع الهوية).
لاستبدال أي منها بصورة فوتوغرافية:

1. ضع الصورة في `public/photos/`
2. أزل التعليق عن اسمها في [`src/data/photos.js`](src/data/photos.js)

الأسماء المتوقّعة: `hero.jpg`, `about.jpg`, `device.jpg`, `pads-30.jpg`, `pads-60.jpg`,
`pads-90.jpg`، ولمعرض صفحة المنتج `device-1.jpg`, `device-2.jpg`, `device-3.jpg` …
ولمشاهد «لمن يناسب» `use-sport.jpg`, `use-sleep.jpg`, `use-run.jpg`, `use-travel.jpg`.

أي اسم غير مسجّل في `photos.js` يُعرض كرسم SVG تلقائياً — **بدون أي طلب شبكة زائد**.

## لوحة التحكم

الرابط: `/admin` — تسجيل دخول حقيقي بالبريد وكلمة المرور (حساب المشرف يُنشأ من الخادم
عبر `npm run seed:admin`، وليس من الواجهة).

تتيح: تعديل الأسعار والكميات وإخفاء/إظهار المنتجات، متابعة الطلبات وتغيير حالتها، فتح أي
طلب في واتساب بضغطة، إنشاء أكواد خصم، وضبط تكلفة التوصيل وعتبة التوصيل المجاني.

كل هذه البيانات مخزَّنة في MongoDB عبر [`server/`](server) — متاحة من أي جهاز أو متصفح،
وكل عملية حسّاسة (السعر، المخزون، الخصم) تُتحقَّق وتُحسَب على الخادم فقط. انظر
[`server/README.md`](server/README.md) للتفاصيل الكاملة عن الواجهة البرمجية.

## آلية الطلب

بدون تسجيل حساب، وبخطوات قليلة:

1. الزائر يضيف منتجاً/باقة أو يستخدم **نموذج الطلب السريع** في الصفحة الرئيسية.
2. عند التأكيد يُنشأ **رقم طلب فريد** بصيغة `OB-XXXXXXX`.
3. تُفتح رسالة واتساب جاهزة تحوي رقم الطلب والمنتجات والمبالغ وبيانات العميل.
4. يرى العميل صفحة تأكيد فيها ملخّص الطلب، ويمكنه متابعته من `/track`.

الدفع عند الاستلام هو الخيار الافتراضي والوحيد المعروض.

## ملاحظات تقنية

- **الأداء:** كود التطبيق ‎~22 kB مضغوط، ومكتبات React في ملف منفصل يبقى مخزّناً بين التحديثات.
  كل صفحة ثانوية تُحمّل عند الحاجة فقط (lazy).
- **SEO:** عنوان ووصف مخصّص لكل صفحة، روابط canonical، وبيانات منظّمة
  (`Product` لصفحات المنتجات و`FAQPage` لصفحة الأسئلة).
- **الحركة:** ظهور تدريجي عبر `IntersectionObserver` مع شبكة أمان تضمن ظهور المحتوى
  حتى لو تعذّر عمل المراقب، واحترام كامل لإعداد `prefers-reduced-motion`.
- **اللغة:** الموقع كله RTL بخطوط Cairo و Tajawal.
- **الصياغة:** كل النصوص تتجنّب الوعود الطبية المطلقة وتستخدم «يساعد» و«قد يدعم»،
  مع تنبيه ظاهر بأن المنتج للاستخدام الخارجي وليس بديلاً عن الاستشارة الطبية.

## البنية

```
src/
  config.js                 إعدادات ثابتة (واتساب، عنوان الخادم، التتبّع)
  analytics.js              GA4 + Meta Pixel (تحميل مؤجّل)
  data/                     المحتوى التسويقي الثابت (مزايا المنتج، الاستخدام، التنبيهات)
  services/api.js           عميل fetch موحّد للتعامل مع server/
  hooks/useAdminAuth.js      جلسة JWT الحقيقية للوحة التحكم
  store/StoreContext.jsx    السلة محلياً + الكتالوج/الطلبات/الكوبونات من الخادم
  components/               الهيكل، الأقسام، الرسوم، النماذج
  pages/                    صفحات الموقع، منها /admin (لوحة تحكم حقيقية)
  styles/                   base (الهوية) · layout (الهيكل) · sections (الأقسام)

server/                     Express + MongoDB — مصدر الحقيقة الوحيد للأسعار والمخزون والطلبات
```

الأسعار والمخزون والاسم لكل منتج تأتي حيّة من `GET /products`؛ المحتوى التسويقي
(الصور، المزايا، خطوات الاستخدام، التنبيهات) يبقى ثابتاً في `src/data/products.js`
ويُدمَج مع البيانات الحيّة في `StoreContext`. أي منتج يعطّله المشرف يختفي تلقائياً
من واجهة المتجر.
